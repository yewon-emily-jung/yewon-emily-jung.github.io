Create 10 TOEFL iBT "Build a Sentence" practice items.
Return ONLY a JSON array, no other text. Each item looks like this:
{"a":"Speaker A's question or statement","pre":"words already shown before the blanks","answer":["chunk1","chunk2","chunk3","chunk4","chunk5"],"post":"words already shown after the blanks","extra":"one wrong chunk","tip":"one-line explanation in Korean of the grammar point"}

Rules:
1. Campus or daily-life topics.
2. "answer" has 4 to 6 chunks. Some chunks are single words and some are short phrases.
3. pre + answer (in order) + post must form exactly one grammatical sentence.
4. There must be only ONE correct order. Using "extra" instead of any answer chunk must make the sentence wrong.
5. "extra" tests a common trap: subject-verb agreement, tense, word form, or an unneeded auxiliary in an indirect question.
6. "pre" or "post" may be an empty string, but not both.
